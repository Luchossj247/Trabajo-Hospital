# HMSPro — Sistema de Gestión Hospitalaria

Aplicación web multi-rol para la administración integral de un hospital. Permite gestionar pacientes, coberturas médicas, turnos, facturación, cola de espera y personal. Construida con **React + Vite**, **Tailwind CSS v4** y **Supabase** como backend.

---

## Cómo correrlo

> Requiere **Node.js >= 20**

```bash
git clone <url-del-repo>
cd proyecto-hospital
npm install
npm run dev
```

La app queda disponible en `http://localhost:5173`.
